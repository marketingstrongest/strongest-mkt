# Meus dados estão seguros na Strongest?

Tags: privacidade, segurança, dados pessoais, LGPD, cartão, site seguro, descadastrar, newsletter

Sim. Nome, endereço, e-mail e telefone cadastrados no site ficam protegidos e em sigilo. Os dados do cartão de crédito são usados apenas no momento da compra e não ficam registrados nos servidores da Strongest. O site tem certificado de segurança (SSL).

A Strongest se compromete a:
- Corrigir os dados pessoais sempre que o cliente informar uma alteração;
- Nunca divulgar nem vender os dados dos clientes;
- Retirar o contato do cliente das listas de e-mail promocional sempre que ele pedir.

Política completa: https://strongest.com.br/pages/seguranca-e-privacidade
